# Detection threshold and event recovery

- Main detector threshold: 4.0 sigma.
- The 5.5-sigma threshold is a supplementary, exploratory comparison.
- Reference codes are used after fitting to calculate agreement and recovery.
- Code 0 is retained as a separate annotation category.
- The threshold sweep is reported in full rather than selecting the maximum-ARI setting.
- The tables show the trade-off between matched-event ARI and event recovery.
- Single-cluster solutions and cluster-count limits are retained for inspection.
